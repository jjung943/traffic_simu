# Roadmap

## Phase 1: Foundation
- Set up repository structure
- Choose initial stack
- Create first runnable version

## Phase 2: First Simulation
- Render a simple road or grid
- Render one car
- Move the car across the screen

## Phase 3: Traffic Behavior
- Add multiple cars
- Add intersections
- Add traffic lights
- Add simple stop/go behavior
- Add different driving landscapes (e.g., residential, freeway)

## Phase 4: Controls and Metrics
- Add start/pause/reset controls
- Add speed controls
- Track basic metrics like car count or wait time

## Phase 5: Variability and complexity
- Add various driver archetypes (e.g., aggressive, average, cautious)
- Assign driver archetypes characteristics
    - Average distance between car and front car 
    - Propensity to switch lanes 
    - Average speed 
    - Aggression  
- Add variability in driver characteristics based on different probability distributions (e.g., normal, Gaussian)
- Add toggles for each of the various behaviors to allow user to modify

## Phase 6: Simulation dashboard
- Add trial log to keep track of results and key characteristics of trial
- Visualize key metrics across numerous trials to understand key factors driving traffic
